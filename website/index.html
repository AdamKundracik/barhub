Frequently Asked Questions

Is the app free?

Yes, basic features like viewing the map, feed, and posting are completely free. Premium features like Travel Mode are paid.

How is occupancy determined?

Occupancy (Full/Almost Full/Sparsely Occupied/Empty) is reported directly by users when posting a photo. This ensures you always get first-hand information.

Are the photos current?

Yes! Photos in the feed expire, so you only see what is happening right now. If a photo is older than 30 minutes, you can request a new one.
